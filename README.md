# theCheetSheet
A code.org app that compiles all the possible resources a high school could ever need (including games :P cuz Chromebooks have everything blocked) 
There is an info page, as well as a settings page where you can change the color of the text. There are 3 main sections
Academics (AP, SAT, Subjects)
Niche stuff(miscallaneous, games)
and Extracurriculars (Olympiads, coming soon)
